Projeto de estudo desenvolvido na Universidade de Brasília (UnB) para praticar lógica de programação, estruturas de dados e desenvolvimento de um jogo em C++.

## 🎯 Objetivo
Desenvolver um jogo de dominó funcional, aplicando conceitos de programação e organização de código.

## 🛠️ Tecnologias
- C++
- STL
- Git/GitHub

## 📚 Conceitos praticados
- `struct` e estruturas de dados
- `vector`
- Manipulação de coleções
- Aleatoriedade e embaralhamento
- Organização de regras de jogo

## 🚀 Execução
Compile o projeto com um compilador C++ compatível e execute o programa pelo terminal.

## 🎓 Contexto
Projeto acadêmico desenvolvido durante os estudos na UnB.
